# Entrega Incremental 6.14 — EventFy

Este pacote contém os artefatos preparados para a etapa descrita no enunciado:

- `PROJETO.md` — consolidação da modelagem, decisões, responsabilidades e conferência;
- `REQUISITOS.md` — requisitos e regras de negócio consolidados;
- `PROCESSOS-NEGOCIO.md` — mapeamento detalhado dos processos reconciliado com requisitos e estados;
- `diagrams/modelo-dominio.md` — modelo de domínio conceitual e estruturação de disponibilidade;
- `diagrams/modelo-dados.md` — modelo de dados relacional derivado com histórico e integridade;
- `diagrams/estados-reserva.md` — diagrama de estados da Reserva (máquina de estados completa);
- `diagrams/sequencia-reserva.md` — diagrama de sequência UML com fluxos principal e alternativos;
- `CONFERENCIA_CRUZADA.md` — formulário de revisão cruzada;
- `prototipo/` — protótipo HTML navegável, incluindo a tela de recusa.

## Como testar o protótipo

Abra `prototipo/index.html` no navegador.

O fluxo principal está preparado para navegar por:
`Início → Catálogo → Serviço → Solicitação → Recusa`

A tela de aprovação também está disponível em `prototipo/aprovada.html`, e a confirmação em `prototipo/confirmada.html`.
